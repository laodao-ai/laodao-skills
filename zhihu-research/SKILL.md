# 知乎搜索词调研

对种子关键词进行知乎搜索调研，发现高价值问题和文章，分析讨论热度和竞争度，输出结构化选题池。

## 知乎内容形态说明

知乎和 B站/YouTube 不同，核心是**问答 + 长文**，不是视频。调研需要关注三种内容类型：

| 类型 | URL 特征 | 调研价值 |
|------|---------|---------|
| **问题** | `zhihu.com/question/xxx` | 需求信号：有人在问 = 有人需要答案 |
| **回答** | `zhihu.com/question/xxx/answer/xxx` | 竞争信号：高赞回答 = 已有好内容 |
| **专栏文章** | `zhuanlan.zhihu.com/p/xxx` | 供给信号：有人在系统性地写 |

**知乎的独特价值：** 搜索权重高（百度/Google 优先收录），长尾流量稳定。一篇好回答可以持续引流半年以上。

## 技术限制

知乎全站封锁 WebFetch（返回 403）。本 skill 完全依赖 WebSearch：
- **WebSearch site:zhihu.com** — 发现内容，获取标题和 URL
- 无法自动获取：赞同数、评论数、关注者数、作者粉丝数
- 这些关键数据需要用户在知乎手动验证

## 输入

通过参数接收种子关键词，格式灵活：
- 逗号分隔：`Claude Code, AI写代码, Spec驱动开发`
- 或直接在对话中提供

## 调研流程

### Phase 1: 多维度搜索

对每个种子词，做 4 次 WebSearch：

**搜索 1 — 发现相关问题和文章：**
```
WebSearch: "site:zhihu.com {种子词}"
```
这是最核心的搜索。从结果中提取所有知乎链接，按 URL 分类为问题/回答/文章。

**搜索 2 — 发现近期内容（活跃度信号）：**
```
WebSearch: "site:zhihu.com {种子词} {当前年份}"
```

**搜索 3 — 发现高赞/高讨论内容：**
```
WebSearch: "site:zhihu.com {种子词} 知乎"
```
有时加"知乎"会触发搜索引擎返回更多知乎热门内容。

**搜索 4 — 发现问答类需求（最有引流价值）：**
```
WebSearch: "site:zhihu.com/question {种子词}"
```
限定搜索问题页面，这些是你可以去回答的。

可以用 Agent 并行搜索不同种子词。

### Phase 2: 数据整理与分类

将搜索结果按内容类型分类整理：

```markdown
### 关键词: {种子词}

**问题（可以去回答引流）：**

| # | 问题标题 | 回答数（估） | 年份 | URL |
|---|---------|------------|------|-----|
| 1 | ... | — | 2026 | https://zhihu.com/question/xxx |

**专栏文章（竞品内容）：**

| # | 文章标题 | 作者 | 年份 | URL |
|---|---------|------|------|-----|
| 1 | ... | — | 2026 | https://zhuanlan.zhihu.com/p/xxx |

**高赞回答（标杆内容）：**

| # | 问题 + 回答摘要 | 年份 | URL |
|---|---------------|------|-----|
| 1 | ... | 2026 | https://zhihu.com/question/xxx/answer/xxx |
```

**URL 分类规则：**
- `zhihu.com/question/数字` → 问题
- `zhihu.com/question/数字/answer/数字` → 回答
- `zhuanlan.zhihu.com/p/数字` → 专栏文章
- 其他 → 标记类型

### Phase 3: 分析判断

**讨论热度（基于搜索结果数量和内容丰富度）：**
- 高：搜索结果 >15条相关内容，有多篇长文和热门问答
- 中：搜索结果 5-15条，有一些讨论
- 低：搜索结果 <5条，话题在知乎上很新
- 无法判断：搜索结果太杂，与话题相关性低

**竞争度（基于专栏文章密度和回答质量）：**
- 高：已有多篇系统性专栏文章，热门问题有多条高质量回答
- 中：有一些文章和回答，但不系统
- 低：几乎没有系统性内容，问题少回答或回答质量低

**引流机会（知乎独有维度）：**
- 寻找"关注者多但好回答少"的问题 — 这是最佳引流机会
- 寻找"近期被提问但尚无好回答"的新问题
- 寻找"搜索量大但知乎内容质量低"的关键词（可以写高质量长文占位）

**蓝海信号：**
- 某关键词搜索结果中问题多但文章少 → 需求存在但没人系统性地写
- 某关键词在B站有流量但知乎讨论少 → 跨平台搬运机会
- 某问题关注者多但高赞回答少于3条 → 你的回答有机会排到前面

### Phase 4: 内容策略分类

知乎的内容策略和 B站/YouTube 不同，分为两种：

**策略 A — 回答问题（引流型）：**
找到高关注、低质量回答的问题，写一个高质量回答，底部引导到公众号/B站。
这是知乎引流的核心方式。

**策略 B — 写专栏文章（占位型）：**
针对搜索量大但知乎内容质量低的关键词，写一篇系统性长文。
知乎文章被百度/Google 收录后，长尾搜索流量稳定。

```
策略矩阵：
                问题多（需求明确）     问题少（需求模糊）
           ┌──────────────────┬──────────────────┐
好回答少   │  ★ 优先回答        │  写文章占位       │
           │  引流效果最好      │  SEO长尾流量     │
           ├──────────────────┼──────────────────┤
好回答多   │  需要更好的回答    │  不做             │
           │  差异化角度切入    │                  │
           └──────────────────┴──────────────────┘
```

## 执行注意事项

- 每个种子词 4 次 WebSearch，5 个种子词 = 20 次搜索。可并行。
- 知乎全站封锁 WebFetch，所有数据来自 WebSearch 的标题和 URL。赞同数、关注者数等**必须手动验证**。
- 从 URL 推断内容类型：`/question/` = 问题，`zhuanlan.` = 文章，`/answer/` = 回答。
- 知乎内容的时效性比视频长。2025年的文章在2026年仍然有搜索流量价值。
- 如果用户同时做了 `/bilibili-research` 或 `/youtube-research`，在输出中增加跨平台对比。检查项目中是否存在其他 `选题池-*.md` 文件。
- **知乎引流的核心公式：** 找高关注问题 → 写高质量回答 → 底部一句话引导到公众号/B站。不要硬广，用"更多实操内容在我的B站频道"这样的软引导。
