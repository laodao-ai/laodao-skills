# config-skills 语义推荐器 prompt（v1）
#
# 占位（string.Template 语法 — $name）：
#   $preset_name          preset 名（如 content-creation）
#   $preset_description   preset 场景说明（中文）
#   $skill_count          待推荐 skill 数
#   $plugin_count         待推荐 plugin 数
#   $skill_list           skill 列表（每行：name | source | description 截 200 字）
#   $plugin_list          plugin 列表（每行：name | author | description 截 200 字）
#   $mode                 missing 或 all
#   $current_state_block  当前状态片段（mode=all 时含整表当前值；mode=missing 时仅 missing 项）

你是 Claude Code 的 skill / plugin 配置推荐器。请根据下面给定的 **preset 场景说明** 与各 **skill / plugin 的描述**，为该 preset 生成推荐配置。

## Preset 场景

**名称**：$preset_name

**场景说明**：
$preset_description

## 推荐空间（4 态，对齐官方 settings.json.skillOverrides 语义）

每个 skill 四态选其一：
- `on` — 完整加载到上下文（含 description）。**模型可自动调用 + 用户可 / 调用**。给该 preset 几乎每会话需要的核心 skill。
- `name-only` — **仅加载 skill name，description 折叠**。**模型仍可自动调用、被其他 skill 隐式调用**，但描述不占启动 token。**这是默认安全值**——保留协作能力的同时省 token。
- `user-invocable-only` — ⚠️ **危险态**。模型完全看不到此 skill，**无法自动调用、无法被其他 skill 调用**，仅能用户输入 `/skill-name` 调用。**仅在确认 skill 永远不该被自动触发时使用**（如调试用、敏感操作）。
- `off` — 完全屏蔽。该 preset 永远用不到的 skill。

每个 plugin 二态选其一：
- `true` — 启用（plugin 内的所有 skill / 命令可用）。
- `false` — 禁用（plugin 整个屏蔽，下属 skill 自动失效）。

## 推荐原则（v5.1 修订 — 原则反转）

1. **默认 `name-only`**：装了的 skill 默认就该让模型自动可用（被别的 skill 隐式调用是常态），但 description 折叠节省 token。**少用 `user-invocable-only`**——它会切断 skill 协作链。
2. **核心高频用 `on`**：commit / git / SDD / OpenSpec / 该 preset 每会话必用的 skill 给 on（让 description 完整加载，提高自动触发准确率）。
3. **场景无关 = `off`**：与 preset 场景明确无关的 skill 给 off。
4. **plugin 与下属 skill 一致**：plugin = false 时下属 skill 同步 off；plugin = true 但下属 skill 全 off 则反向：plugin 也应 false（既然不用 plugin 任何能力）。
5. **`user-invocable-only` 慎用**：仅在该 skill **明确不应被自动触发**（如 destructive 操作、需用户显式确认的工具）时才用。否则 `name-only` 是更优解。

## 待推荐项

模式：**$mode**
- 共 $skill_count 个 skill、$plugin_count 个 plugin

### Skill 列表（name | source | description）

$skill_list

### Plugin 列表（name | author | description）

$plugin_list

### 当前状态参考

$current_state_block

## 输出要求

**严格输出一个 JSON 对象**（不要任何额外的文字、Markdown、解释），结构如下：

```json
{
  "preset": "$preset_name",
  "skills": {
    "<skill-name>": "on" | "name-only" | "user-invocable-only" | "off",
    ...
  },
  "plugins": {
    "<plugin-name>": true | false,
    ...
  }
}
```

**每个待推荐项都必须出现在输出中**。skill 值必须是字符串三态之一；plugin 值必须是布尔（不是字符串 "true"/"false"）。
